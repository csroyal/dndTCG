# Card effect sounds

Drop `.mp3` files in this folder using the names below and they play automatically with the
matching card effect (scripts/effects.js). Any file that isn't here is skipped silently, so add
them in any order. Keep them short (under ~2s) and trimmed so the sound starts right away.

## Creature types (play when a Summon lands)
| File | Used for |
|---|---|
| dragon.mp3 | Roar for Dragon summons, draconic cards, Gold Dragons, Hydra's second and third heads |
| breath.mp3 | Fire/frost breath whoosh, layered after the roar |
| undead.mp3 | Ghostly moan / wail |
| beast.mp3 | Growl or snarl with a claw swipe |
| machine.mp3 | Gears clank, steam hiss |
| fey.mp3 | Magical chime / twinkle |
| fiend.mp3 | Demonic growl with fire crackle |
| plant.mp3 | Creaking wood, rustling leaves |
| entity.mp3 | Arcane hum swelling into a burst |
| humanoid.mp3 | Sword shing / heroic glint |
| summon.mp3 | Generic summon (cards with no creature type) |

## Elements and themes (mostly Spells)
fire, cold, lightning, thunder, force, necrotic, radiant, poison, acid, psychic, healing,
time, earth, arcane, utility, reaction (all `.mp3`)

## Categories
| File | Used for |
